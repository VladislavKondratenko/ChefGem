=== ГЛОБАЛЬНИЙ КУМУЛЯТИВНИЙ КАТАЛОГ ТОВАРІВ: СІЛЬПО (ЧЕРНІГІВ) ===

**Формат:** Мережа супермаркетів (асортимент без прив'язки до брендів)
**Особливості:** Власний імпорт, Лавка Традицій (крафт), Власна кондитерська, Риба власного копчення

--- 🥬 СВІЖІ ПРОДУКТИ, ОВОЧІ ТА ФРУКТИ ---

[Овочі «Борщового набору» та коренеплоди]

Категорія: Картопля

- картопля біла / жовта вагова (стандартна, немита)
- картопля рожева / червона вагова (ідеальна для смаження)
- картопля мита добірна (калібрована, у сітках по 1 кг / 2 кг / 2.5 кг)
- картопля молода вагова (рання місцева / імпортна сезонна)
- картопля молода мита міні («бейбі-картопля» для запікання)
- картопля органічна (Органік / БІО, у спеціальних пакуваннях)
- картопля фіолева / синя (екзотичні сорти з антоціанами)
- картопля очищена у вакуумній упаковці (натуральний напівфабрикат кулінарії)

Категорія: Капуста

- капуста білокачанна врожаю минулого року (вагова)
- капуста білокачанна молода рання (сезонна)
- капуста червонокачанна (синя / пурпурова)
- капуста пекінська вагова
- капуста савойська (гофрована кучерява)
- капуста конічна (солодка ранньостигла)
- капуста білокачанна шаткована (свіжа нарізка в пластикових контейнерах)

Категорія: Буряк

- буряк столовий круглий ваговий (немитий)
- буряк сорту «Циліндра» (видовжений, солодкиий)
- буряк митий добірний (фасований у сітки)
- буряк молодий з бадиллям (сезонний, у пучках)
- буряк варений очищений цілий (у вакуумній упаковці)
- буряк варений натертий / нарізаний кубиком (готовий напівфабрикат)
- буряк органічний БІО

Категорія: Морква

- морква столова вагова (стандартна, немита)
- морква мита добірна (калібрована, у пакетах або на вагу)
- морква рання молода (сезонна)
- морква молода з хвостиками (у пучках)
- морква міні / «бейбі» солодка (очищена, у пакетах для перекусу)
- морква варена очищена у вакуумній упаковці
- морква по-корейськи (свіжа соломка без заправки у прозорих боксах)
- морква органічна БІО

Категорія: Цибуля ріпчаста

- цибуля ріпчаста жовта класична (вагова)
- цибуля ріпчаста жовта мита добірна (у сітках)
- цибуля солодка біла (імпортна, з м'яким смаком)
- цибуля фіолетова / червона (сорт «Марс» або «Ялтинська»)
- цибуля-шалот (делікатесна, дрібна, у сіточках)
- цибуля ріпчаста дрібна (для маринування / саджанка)
- цибуля ріпчаста очищена у вакуумі

Категорія: Часник

- часник ваговий сухий
- часник молодий зелений (ранній сезонний)
- часник фасований елітний (у сіточках по 3-4 шт.)
- часник однозубковий (круглий імпортний)
- часник очищений (зубчики в пластикових контейнерах)

Категорія: Традиційні та дієтичні коренеплоди

- корінь селери ваговий (очищений від землі)
- корінь пастернаку (білий корінь)
- корінь петрушки ваговий
- набір овочевий «Для борщу / супу» (мікс: шматок селери, пастернаку, морква, цибуля на підкладці)
- редиска вагова (сезонна)
- редиска у пучках із зеленню
- редиска біла довга / Дайкон
- редька чорна зимова (гостра)
- редька зелена маргеланська
- редька кавунова (із рожевою серцевиною)
- топінамбур (земляна груша)
- батат (солодка картопля, імпортний, з помаранчевою або білою м'якоттю)
- хрін (свіжий корінь)

[Тепличні та сезонні овочі]

Категорія: Помідори (Томати)

- помідори червоні круглі вагові (класичні тепличні)
- помідори ґрунтові червоні (сезонні українські, для консервації)
- помідори сорту «Сливка» (червоні, жовті, рожеві)
- помідори рожеві великі салатні (вагові, м'ясисті)
- помідори жовті / помаранчеві круглі
- помідори на гілці (кластерні, середнього калібру)
- помідори Чері червоні вагові
- помідори Чері на гілці (у пластикових або картонних лотках під плівкою)
- помідори Чері жовті / шоколадні / рожеві (фасовані)
- помідори чорні / темно-бордові (сорт «Кумато»)
- помідори коктейльні (калібровані, солодкі преміум-сорти)
- томати колекційні елітні (гібриди з підвищеним вмістом цукру)
- томати органічні БІО (сертифіковані, в індивідуальній упаковці)

Категорія: Огірки

- огірки довгі гладкі (тепличні, переважно зимово-весняний імпорт)
- огірки середньоплодні гладкі вагові
- огірки короткоплодні колючі (хрусткі тепличні)
- огірки ґрунтові щільні (сезонні, для домашнього засолювання)
- огірки-корнішони міні (хрусткі добірні, у лотках або пакетах)
- огірки гладкі міні (гладкі порційні огірочки для дитячих перекусів)
- огірки органічні БІО

Категорія: Перець солодкий та пікантний

- перець болгарський зелений ваговий (сезонний місцевий / імпортний)
- перець болгарський жовтий товстостінний (кубовидний преміум-імпорт)
- перець болгарський червоний великий
- перець болгарський помаранчевий
- перець солодкий сорту «Білозерка» (грунтовий світло-жовтий, для фарширування)
- перець солодкий довгий сорту «Капі» (червоний / конічний)
- перець Ратунда / Гогошари (круглий м'ясистий)
- мікс солодких перців міні (солодкі різнокольорові перчики в пакетах)
- перець солодкий органічний БІО

Категорія: Перець гострий

- перець гострий Чилі червоний (ваговий / поштучно)
- перець гострий Чилі зелений
- перець гострий сорту «Халапеньйо» (зелений / червоний)
- перець ультра-гострий (Хабанеро, Кароліна Ріпер або аналоги в мікро-пакетах)
- перець гострий довгий (для маринування)

Категорія: Кабачки та баклажани

- кабачки білоплідні молоді вагові (тепличні та ґрунтові)
- кабачки сорту «Цукіні» (темно-зелені, жовті, смугасті)
- кабачки круглі (порційні, для фарширування)
- кабачки свіжі нарізані кружальцями (напівфабрикат кулінарії)
- баклажани класичні фіолетові вагові
- баклажани білі (ніжні, без гіркоти)
- баклажани круглі / графіті (із біло-фіолетовими смугами)

Категорія: Гарбузи

- гарбуз звичайний круглий (ваговий, цілий або нарізаний шматочками у плівці)
- гарбуз сорту «Баттернат» (мускатний, грушоподібний, солодкий)
- гарбуз сорту «Гітара» (довгий, м'ясистий)
- гарбузи порційні міні
- гарбуз очищений нарізаний кубиком (у вакуумі)

Категорія: Кукурудза та сезонні бобові

- кукурудза цукрова в качанах (вагова, в листі)
- кукурудза цукрова очищена (по 2-3 шт. на підкладці у вакуумі/плівці)
- стручкова квасоля свіжа спаржева (зелена, жовта вагова)
- зелений горошок у стручках (сезонний)
- боби свіжі в стручках

[Капуста, гриби та екзотичні овочі]

Категорія: Свіжі культивовані та лісові гриби

- печериці білі класичні вагові (дрібні, середні, великі)
- печериці білі королівські (крупні, щільні, під плівкою)
- печериці бурі / коричневі (із більш вираженим грибним ароматом)
- печериці гігантські «Портобелло» (для запікання та бургерів, поштучно або в лотках)
- глива звичайна (вешенка, гронами вагова / фасована)
- гриби Ерінґі (королівська глива, товсті білі ніжки)
- гриби Шиїтаке (азійські делікатесні, фасовані в пластикових боксах)
- гриби Енокі / Золоті нитки (тонкі білі гриби на довгих ніжках)
- гриби Шімеджі (білі / коричневі, у міні-упаковках)
- гриби лісові свіжі (білі, лисички, підберезники — сезонні надходження)
- гриби органічні БІО

Категорія: Свіжі різновиди капусти

- капуста цвітна вагова (класична біла, з листям)
- капуста цвітна добірна зачищена (у стрейч-плівці)
- капуста цвітна кольорова (фіолетова / жовта / помаранчева, сезонний імпорт)
- капуста броколі вагова
- капуста броколі фасована (калібровані суцвіття на підкладці)
- капуста Романеско (екзотична коралова капуста, зелена пірамідальна)
- капуста брюссельська свіжа вагова
- капуста брюссельська на стеблі (сезонна)
- капуста кольрабі зелена (стеблоплід з легким солодким смаком)
- капуста кольрабі фіолетова
- капуста Кейл / Кале зелена кучерява (суперфуд)
- капуста Кейл / Кале фіолетова
- капуста пак-чой (китайська черешкова капуста міні)
- капуста савойська (із ніжною гофрованою структурою листя)

Категорія: Спаржа та артишоки

- спаржа зелена (аспарагус свіжий, у пучках по 250г / 450г)
- спаржа біла (делікатесна, вирощена без світла)
- спаржа фіолетова (сезонний преміум-імпорт)
- артишоки свіжі великі (поштучно)

Категорія: Екзотичні та ресторанні овочі

- стебло селери (черешкова селера, соковита, в упаковках)
- фенхель свіжий (корінь-цибулина з анісовим ароматом)
- пастернак (білий корінь)
- імбир (свіжий корінь, ваговий)
- топінамбур (земляна груша)
- батат класичний (солодка картопля з помаранчевою м'якоттю)
- батат білий / фіолетовий (дієтичні імпортні сорти)
- окра (бамія, дамські пальчики, свіжа в лотках)
- пагони бамбука свіжі (сезонний імпорт)
- лотосовий корінь свіжий

[Свіжа зелень, салати та мікрогрін]

Категорія: Повсякденна та пряна зелень

- кріп свіжий ваговий
- кріп свіжий у пучках (фасований у пакети)
- петрушка гладка листова ваговая
- петрушка кучерява (декоративна, у пучках)
- цибуля зелена (перо, вагова та в пучках)
- кінза / коріандр свіжий (у пучках)
- щавель свіжий (сезонний, у пучках)
- шпинат свіжий ваговий (великі щільні листи)

Категорія: Жива зелень та трави в горщиках (З кореневою системою)

- салат листовий зелений у горщику (у фірмовому конусному пакуванні)
- базилік зелений у горщику (жива ароматна пряність)
- базилік фіолетовий у горщику
- м'ята перцева у горщику
- петрушка / кріп у горщиках
- розмарин / чебрець у горщиках (для довгого домашнього використання)

Категорія: Листові качанні та кучеряві салати

- салат Айсберг (хрусткий качанний, у захисній плівці)
- салат Ромен / Романо (поштучно / у пакетах по 2 шт., основа для Цезаря)
- салат Латук класичний ваговий
- салат Лолло Россо (кучерявий бордово-червоний)
- салат Лолло Біонда (кучерявий яскраво-зелений)
- салат Фрізе (кучерявий ендівій з пікантною гірчинкою)
- салат Радічіо / Радіккьо (качанний салат пурпурового кольору з білими прожилками)
- салат Цикорій / Ендівій (маленькі щільні біло-жовті качанчики)

Категорія: Мита бебі-зелень та готові салатні мікси (Ready-to-Eat)

- рукола свіжа (молоді бебі-листи, в упаковках 75г / 125г / 200г)
- шпинат бебі (ніжні міні-листи, фасовані в контейнери)
- мангольд бебі (бурякові листи з яскравими прожилками)
- маш-салат / корн (маленькі круглі розетки листя з горіховим присмаком)
- мікс салатний «Італійський» (радічіо, фрізе, ромен)
- мікс салатний «Фітнес» / «Тонус» (рукола, бебі-шпинат, мангольд)
- мікс салатний «Цезар» (нарізаний ромен / айсберг, пекінська капуста)
- мікс салатний «Грецький» (великі хрусткі шматочки листкових салатів)
- мікс салатний з качанного салату та тертої червоної капусти / моркви
- салатні міксі БІО / органічні (миті, у спеціальних екологічних лотках)

Категорія: Свіжий мікрогрін (Мікрозелень у пластикових контейнерах)

- мікрогрін гороху (солодкі вусики та стебла)
- мікрогрін соняшника (м'ясисті соковиті паростки)
- мікрогрін редису / дайкону (з характерним гострим присмаком)
- мікрогрін люцерни / крес-салату
- мікрогрін броколі / червоної капусти
- мікрогрін мікс (суміш різних пророслих культур)
- паростки пшениці / жита (для приготування вітграсу та смузі)

Категорія: Преміальні свіжі пряні трави (У герметичних блістерах / лотках)

- базилік зелений / фіолетовий (добірні листи в лотках)
- м'ята свіжа добірна (великі пучки для коктейлів та десертів)
- меліса лимонна свіжа
- розмарин свіжий (гілочки, ідеально до м'яса)
- чебрець / тим'ян свіжий (у міні-боксах)
- тархун / естрагон свіжий
- шавлія свіжа (оксамитові листи)
- орегано / майоран свіжий (преміум-імпорт)
- лемонграсс / лимонне сорго (жорсткі стебла для пасти Том Ям)
- листя кафрського лайма свіже (для азійських супів)

[Фрукти місцеві, ягоди та баштанні]

Категорія: Яблука (З деталізацією сортів)

- яблука сорту «Голден Делішес» (солодкі, жовто-зелені)
- яблука сорту «Гала» / «Роял Гала» (соковиті, червоно-строкаті)
- яблука сорту «Симиренко» (тверді, зелені, кислуваті)
- яблука сорту «Чемпіон» (тонкошкірі, солодкі великі)
- яблука сорту «Айдаред» (глянцеві червоні, зимові)
- яблука сорту «Джонаголд» / «Джонапринц» (інтенсивно-червоні)
- яблука сорту «Гренні Сміт» (преміум-імпорт, яскраво-зелені, кислі, суперхрусткі)
- яблука сорту «Фуджі» (тверді, медово-солодкі)
- яблука ранні «Білий налив» (сезонні місцеві)
- яблука дрібні фасовані в пакетах (економ-серія ТМ «Повна Чаша» або «Премія»)
- яблука органічні БІО (сертифіковані, в індивідуальних лотках під плівкою)

Категорія: Груші

- груші сорту «Конференція» (видовжені зелено-коричневі, соковиті та м'які)
- груші сорту «Лимонка» / «Улюблена Клаппа» (ранні сезонні)
- груші сорту «Киргизька» (зимові, щільні з червоним бочком)
- груші сорту «Ноябрська» (великі десертні груші преміум-класу)
- груші сорту «Пакхам» (імпортні зелені горбкуваті)
- груші китайські «Наші» (екзотичні, круглі як яблука, хрусткі й водянисті)
- груші органічні БІО

Категорія: Кісточкові фрукти (Місцеві та імпортні)

- сік яблучний освітлений (фільтрований, прозорий, фасування від 0.2л до 2л)
- сік яблучний неосвітлений (з м'якоттю, натуральний каламутний)
- сік апельсиновий відновлений 100% (класичний сніданковий варіант, Власний імпорт)
- сік апельсиновий з підвищеним вмістом м'якоті (Pulp Juice)
- сік томатний з морською або кухонною сіллю (густий, гомогенізований)
- сік томатний без солі (дієтичний)
- сік ананасовий (100% відновлений, солодкий)
- сік грейпфрутовий (рожевий або білий, з благородною гірчинкою)
- сік гранатовий (у скляних пляшках по 1л, терпкий, Власний імпорт)
- соки прямого віджиму (NFC - Not From Concentrate, пастеризовані, преміум-серії у склі чи Тетра-паках: яблуко, яблуко-груша, яблуко-морква, мультивитамин)
- соки органічні БІО (сертифіковані, без пестицидів)

Категорія: Фруктові та ягідні нектари й морси (Вміст соку 25–50%)

- нектар мультифрукт / тропік (мікс соків: ананас, манго, маракуйя, апельсин, банан, гуава, ТМ «Премія»)
- нектар персиковий / абрикосовий (густий, з великим вмістом м'якоті)
- нектар вишневий (кисло-солодкий, яскравий рубіновий колір)
- нектар виноградний (із білого або червоного європейського винограду)
- нектар яблучно-виноградний (універсальний повсякденний мікс)
- нектар банановий / бананово-полуничний (густий, солодкий)
- нектар чорносмородиновий / чорничний / лохиновий
- морс журавлинний (традиційний освіжаючий напій із легким терпким смаком)
- морс брусничний / мікс лісових ягід

Категорія: Овочеві, екзотичні соки та натуральні смузі

- сік березовий натуральний (у великих скляних банках по 3л або Тетра-паках 1л)
- сік березовий з додаванням цукру та лимонної кислоти / настійної трави шипшини / м'яти
- сік морквяний / морквяно-яблучний (вітамінізований, з м'якоттю)
- сік гарбузовий (густий, солодкий)
- мультиовочевий сік (мікс: томат, буряк, морква, селера, солодкий перець)
- напої соковмісні негазовані (легкі освіжаючі напої з вмістом соку 10–12%, ТМ «Повна Чаша»)
- сік алое вера з шматочками м'якоті (у пластикових пляшках, азійський імпорт)
- натуральні густі смузі у пляшечках з холодильника кулінарії (мікси: банан-полуниця, манго-маракуйя, зелений ківі-шпинат-яблуко, Ready-to-Drink)

Категорія: Дитячі соки та напої (З підвищеним контролем якості)

- сік дитячий яблучний / грушевий гіпоалергенний (у маленьких пачках по 0.2л із трубочкою, дозволений з 4-6 місяців)
- сік дитячий яблуко-банан / яблуко-персик з м'якоттю
- сік дитячий мультифрукт вітамінізований
- сік дитячий у скляних пляшечках по 0.175л / 0.2л
- смузі дитяче фруктове в м'яких паучах із кришечкою ( Ready-to-Go перекус на основі фруктових пюре)

Категорія: Великі сімейні формати пакування

- сік / нектар у великих картонних коробках Family Pack (по 1.5л / 2л / 3л)
- сік у пакетах Bag-in-Box (велика коробка 3л / 5л із вбудованим краником-дозатором, переважно прямого віджиму)

[Вода питна, мінеральна та солодкі газовані напої]

Категорія: Вода питна та столова (Повсякденна бутильована)

- вода питна негазована очищена (артезіанська, об'єми 0.5л / 0.75л / 1л / 1.5л / 2л)
- вода питна негазована у великих суліях (сімейне фасування 5л / 6л / 10л)
- вода питна сильногазована класична (у ПЕТ-пляшках)
- вода питна слабогазована / середньогазована
- вода питна негазована спорт-формат (пляшки 0.5л / 0.75л зі спеціальним клапаном-дозатором для тренувань)
- вода питна дитяча (із мінімальним ступенем мінералізації, дозволена з перших днів життя, фасування від 0.33л до 5л)

Категорія: Вода мінеральна природна та лікувально-столова (Включаючи Власний імпорт)

- вода мінеральна природно-столова гідрокарбонатна (природної газованості, у склі або пластику, великий вибір українських курортних брендів)
- вода мінеральна лікувальна високомінералізована (лужна, з характерним солонуватим смаком, типу Боржомі, Поляна Квасова)
- вода мінеральна хлоридно-натрієва / сульфатна
- вода мінеральна імпортна преміальна (у скляних пляшках, з вулканічних джерел чи альпійських льодовиків: Сан-Пеллегріно, Евіан, Пер'є, Власний імпорт)
- вода мінеральна газована з натуральним соком або ароматом (лимон, лайм, м'ята, полуниця, лохина, без цукру та калорій)

Категорія: Солодкі газовані напої та лимонади

- напій газований «Кола» класичний (з цукром, фасування від бляшанок 0.33л до пляшок 2л)
- напій газований «Кола» без цукру (Zero / Light, на підсолоджувачах)
- напій газований цитрусовий «Апельсин» (класична помаранчева газировка з додаванням натурального соку)
- напій газований лимон-лайм / прозорий освіжаючий (типу Спрайт)
- напій газований тонік (із характерним гіркуватим смаком хініну, для коктейлів)
- напій газований класичний вітчизняний («Лимонад», «Тархун» зелений, «Ситро», «Крем-сода», «Дюшес», ТМ «Премія»)
- напій газований екзотичний (зі смаком манго, маракуйї, граната, кавуна, кактуса)
- напої солодкі газовані бюджетні (на штучних підсолоджувачах, економ-серія ТМ «Повна Чаша»)

Категорія: Квас та напої натурального бродіння

- квас житній класичний живого бродіння (темний, насичений, у ПЕТ-пляшках 1л / 1.5л / 2л)
- квас білий окрошковий (кислуватий, нефільтрований, ідеальний для літніх супів)
- квас хлібний лагідний / медовий (солодкуватий)
- квас смородиновий / журавлинний / з м'ятою (сезонні ягідні лінійки бродіння)
- комбуча (напій на основі чайного гриба, газований, натурального бродіння з різними смаками у склі, трендовий здоровий напій)

Категорія: Енергетичні та спортивні напої (Тонізуючі)

- енергетичний напій класичний (із високим вмістом кофеїну, таурину та вітамінів групи B, у залізо-бляшанках 0.25л / 0.5л)
- енергетичний напій без цукру (дієтичний, на підсолоджувачах)
- енергетичний напій фруктовий / тропічний (зі смаком манго, кавуна, кокоса, лісових ягід)
- енергетичний напій преміальний імпортний (ексклюзивні смакові лінійки)
- ізотонік / спортивний напій (із відновлювальним комплексом електролітів, солей та мінералів для спортсменів, яскравих кольорів: синій, помаранчевий)

Категорія: Холодний чай (Ice Tea)

- холодний чай чорний зі смаком лимона (у ПЕТ-пляшках від 0.5л до 1.5л)
- холодний чай чорний зі смаком персика
- холодний чай зелений класичний / з лимоном та м'ятою
- холодний чай білий / фруктовий (каркаде, полуниця-малина)

[Заморожені напівфабрикати (Пельмені, вареники, готові страви)]

Категорія: Пельмені класичні та м'ясні (Вагові та фасовані)

- пельмені зі свининою та яловичиною (традиційні «Домашні» або «Сибірські», фасування від 400г до 1кг+, великий вибір ТМ «Премія»)
- пельмені виключно зі свининою (соковиті, з цибулею та чорним перцем)
- пельмені виключно з яловичиною / телятиною (пісні, щільні)
- пельмені з курячим фаршем (дієтичні, полегшені)
- пельмені з м'ясом індички (ніжні, дитячі/фітнес серії)
- пельмені «Міні» / дитячі (дрібного калібру, часто з додаванням натуральних соків у тісто для кольору: зелені зі шпинатом, рожеві з буряком)
- пельмені преміум-класу з рубленим м'ясом (замість фаршу)
- пельмені вагові заморожені (економ-варіант у боксах самообслуговування)

Категорія: Хінкалі, манти та великі м'ясні напівфабрикати з тіста

- хінкалі класичні з яловичиною та свининою (із додаванням кінзи та грузинських спецій, великі, зі складками)
- хінкалі з курятиною та сиром сулугуні
- хінкалі гострі з перцем чилі
- манти з бараниною / міксом м'яса та курдючним жиром
- равіолі італійські з м'ясом та зеленню
- чучвара (мініатюрні середньоазійські пельмені для супу)

Категорія: Вареники з несолодкими (Гастрономічними) начинками

- вареники з картоплею класичні (вагові та у пачках)
- вареники з картоплею та смаженою цибулею / картоплею та кріпом
- вареники з картоплею та лісовими грибами / печерицями
- вареники з картоплею та шкварками / беконом
- вареники з квашеною або свіжою тушкованою капустою
- вареники з картоплею та капустою (мікс-начинка)
- вареники з лівером (серце, легені, печінка)
- вареники з м'ясом (готовим відварним м'ясом свинини або яловичини)
- вареники з солоним кисломолочним сиром та кропом

Категорія: Вареники зі солодкими та ягідними начинками

- вареники з солодким кисломолочним сиром та ваніллю
- вареники з солодким сиром та родзинками
- вареники з вишнею натуральною цілою без кісточки (у літній та зимовий сезон)
- вареники з полуницею / чорницею / лісовими ягодами
- вареники з маковою начинкою

Категорія: Заморожені м'ясні, рибні та рослинні вироби (Готові до смаження)

- нагетси курячі класичні в хрусткій паніровці (вагові та в коробках)
- нагетси курячі з сирною начинкою усередині
- котлети курячі / свино-яловичі для бургерів (пласкі круглі диски)
- котлети «По-київськи» заморожені (з вершковим маслом та зеленню всередині)
- палички рибні в паніровці (з білих сортів риби / сурімі)
- стейки з рибного фаршу / бургери рибні заморожені
- котлети рослинні / веганські (на основі соєвого або горохового білка, типу Beyond Meat або аналоги)
- млинці заморожені з м'ясом (готовий закручений напівфабрикат)
- млинці заморожені з солодким сиром та родзинками / з вишнею
- чебуреки з м'ясом заморожені (швидкого приготування)

[Заморожені овочі, ягоди та морозиво]

Категорія: Заморожена картопля та гастро-напівфабрикати

- картопля фрі заморожена соломкою (товщина 6мм / 9мм, у пакетах по 0.5кг / 1кг / 2.5кг)
- картопляні дипи / дольки по-селянськи (із запеченою шкіркою та спеціями)
- картопляні крокети / кульки з пюре в паніровці
- кільця цибулеві в паніровці заморожені (для фритюру)

Категорія: Заморожене тісто та основи

- тісто листкове дріжджове (рулони або пластини під плівкою)
- тісто листкове бездріжджове (для слойок та наополеону)
- тісто витяжне «Філо» (ультратонкі напівпрозорі листи)
- тісто для піци (готові круглі заморожені коржі-основи, соус у комплекті або без)
- тісто здобне / пісочне заморожене

Категорія: Шоково-заморожені овочі та суміші (Вагові та в пакетах)

- овочева сумісь «Мексиканська» (мікс: кукурудза, зелений горошок, стручкова квасоля, болгарський перець, морква)
- овочева сумісь «Гавайська» (мексиканський мікс овочів + білий відварний рис)
- овочева сумісь «Весняна» / «Європейська» (суцвіття цвітної капусти та броколі, міні-морква, брюссельська капуста)
- суміш овочева для супу / борщу (нарізані буряк, картопля, капуста, зелень)
- суміш для смаження WOK (з додаванням паростків бамбука, грибів муер та китайської капусти)
- броколі / цвітна капуста суцвіттями (окреме фасування)
- шпинат заморожений (листовий у брикетах / подрібнений пресований кульками)
- стручкова квасоля спаржева (різана, зелена / жовта)
- зелений горошок / кукурудза солодка зернами
- гриби печериці різані скибками / білі гриби заморожені шматочками

Категорія: Заморожені фрукти, ягоди та суміші

- вишня заморожена ціла без кісточки (універсальна для випічки)
- полуниця заморожена (цілі великі ягоди)
- малина / ожина / лохина шокової заморозки
- смородина чорна / порічки червоні
- журавлина / брусниця заморожена (зимовий вітамінний ряд)
- ягідний мікс (полуниця, малина, смородина, ожина для компотів та смузі)

Категорія: Морозиво (Десертна заморозка)

- морозиво пломбір класичний білий (у вафельному стаканчику, 10–12% / 15% жирності, великий вибір преміум-виробників)
- морозиво шоколадне / кокосове / кавове / фісташкове у стаканчиках
- морозиво ескімо на паличці в шоколадній глазурі (білій, молочній, чорній, з горіхами або сублімованою малиною)
- морозиво ріжок великий (з джемовим, шоколадним чи карамельним стрижнем усередині)
- морозиво фруктовий лід / щербет (заморожений натуральний сік або фруктове пюре)
- морозиво великого сімейного формату (у пластикових ванночках або термопакетах по 0.5кг / 1кг, ТМ «Премія»)
- морозиво відро преміум-серії (з топінгами, макаронсами, печивом, шматочками фруктів чи солоною карамеллю)
- морозиво безлактозне / веганське на кокосовому чи мигдальному молоці

[Спеціальне харчування (Безглютенове, безцукрове, біо)]

Категорія: Безглютенові продукти (Gluten-Free, марковані перекресленим колоском)

- борошно безглютенове універсальне кондитерське (у пачках, Власний імпорт)
- суміш безглютенова для випікання хліба / піци / млинців
- макаронні вироби безглютенові (на основі кукурудзяного, рисового, сочевичного або нутового борошна: спагетті, пенне, фузілі)
- хліб тостовий безглютеновий (у спеціальній герметичній упаковці з тривалим терміном зберігання)
- печиво, вафлі та бісквіти безглютенові (десертний імпортний ряд)
- хлібці безглютенові (рисові, кукурудзяні, гречані, амарантові)
- сухі сніданки / пластівці безглютенові (кукурудзяні пластівці, гранола)

Категорія: Продукти без цукру та для діабетиків (Sugar-Free)

- шоколад дієтичний без цукру (молочний, чорний, білий, на стевії, еритритолі або мальтитолі)
- цукерки, батончики та льодяники без цукру (з додаванням натуральних соків та підсолоджувачів)
- печиво, вафлі та кекси без цукру (на основі цільнозернового борошна та замінників)
- джеми, варення та конфітюри без цукру (на пектині, дієтичні заправки для сиру)
- натуральні замінники цукру (стевія в таблетках чи порошку, еритритол, сироп топінамбура / агави)
