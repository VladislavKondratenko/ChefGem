# OUTPUT TEMPLATE: STAGE C (ATOMIC TECHNICAL CARD)

When the user provides affirmative confirmation to the Stage B audit, generate the complete Atomic Technical Card.
All sections from C.1 to C.6 are **MANDATORY**. Omitting any section is a critical execution error.

### Required Language:
Generate user-facing text in Ukrainian (or the language the user is speaking).

### Schema:

---

## АТОМАРНА ТЕХНОЛОГІЧНА КАРТА (ТК): [Назва страви] (v[X.X])

##### C.1. Summary & Physics
* **Метадані:** Назва страви, версія ТК, короткий культурно-гастрономічний контекст.
* **Концепція:** Цільовий органолептичний, смаковий і текстурний профіль.
* **Фізико-хімічна модель:** Тип колоїдної або білкової системи (емульсія о/в, гідрогелевий матрикс, коагуляція міозину/актину), ключові хімічні реакції (реакція Майяра, карамелізація, деградація колагену).

##### C.2. Специфікація (Таблиця інгредієнтів)
*Вимога: Стандартна Markdown-таблиця. Кожен інгредієнт — в окремому рядку. Одиниці — тільки грами [г].*

| Інгредієнт | Брутто (г) | Нетто (г) | Примітка (технологічна функція) |
| :--- | :--- | :--- | :--- |
| [Назва сировини] | [г] | [г] | [Функція в системі; для штучних вказати кількість, напр. 2 шт.] |

##### C.3. Execution Steps: Атомарний Алгоритм
*Кожен крок описується як окрема мікро-операція, адаптована для початківця:*
1. **Операція та обладнання:** Конкретна дія (подрібнення, емульгування, високотемпературне обсмажування) та точний інструмент із наявного кухонного обладнання.
2. **Параметри контролю (KPI):**
   * *Температурні:* Температура продукту та середовища (°C), Target Core Temp.
   * *Часові:* Точний таймінг у секундах [сек] (для високотемпературних/зсувних операцій) або хвилинах/годинах [хв/год] (для су-віду, відпочинку).
   * *Сенсорні маркери:* Фізичні маркери завершення фази (акустична зміна звуку блендера при зростанні в'язкості, набуття глянцевого сатинового блиску, пружний відгук білка, інтенсивність шкварчання).
3. **Scientific "Why":** Біохімічне та фізичне пояснення дії (осмотичний тиск, стабілізація емульсії, запобігання денатурації).
4. **Fail-safe & Recovery:**
   * *Сценарій А:* Виправлення відхилень (напр., стабілізація при розшаруванні емульсії).
   * *Сценарій Б:* Термобуфер при ризику перегріву.

##### C.4. Аудит SFAH (Баланс 4 стихій)
* **Salt:** Концентрація солі від маси (%), тип солі, осмотичний таймінг внесення.
* **Fat:** Джерело ліпідів, концентрація (суворо <= 20г/100г), якість mouthfeel без маслянистості.
* **Acid:** Джерело кислотності, баланс pH, свіжість та маскування дієтичного профілю.
* **Heat:** Метод передачі енергії (кондукція, конвекція, випромінювання), збереження вологи.

##### C.5. Service, Plating & Storage
* **Презентація:** Схема викладки (геометрія, висота, контраст).
* **Температура подачі:** Точне цільове значення (°C) при подачі гостю.
* **Умови та термін зберігання:** Температура (°C), тип тари, граничний Shelf Life за стандартами HACCP.

##### C.6. Nutrition & Tracking Block
1. **Склад страви:** Короткий перелік готових нетто-інгредієнтів через кому.
2. **КБЖВ на 100г готового продукту (з урахуванням Shrinkage):** Обов'язково:
   * Білки: [X]г | Жири: [Y]г | Вуглеводи: [Z]г | Калорійність: [N] ккал.
3. **КБЖВ на 1 порцію (нетто):** Додатковий розрахунок на порцію.
4. **Data for Tracking (Code Block):** Текстовий блок для внесення у трекери (CalZen / FatSecret):
```text
[Назва страви]: [Склад нетто через кому]. КБЖВ на 100г: Б:[X], Ж:[Y], В:[Z], Ккал:[N].
```
